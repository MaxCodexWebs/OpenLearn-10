Control Flow @logic • 2 Std.

Lektion 2: Bedingungen (`if`, `elif`, `else`) und Schleifen (`for`, `while`). Code wird basierend auf Logik ausgeführt!

score = 85

if score >= 90:
    print("Exzellent! 🏆")
elif score >= 70:
    print("Gut gemacht! 👍")
else:
    print("Übe noch ein bisschen!")

Functions @def_func • 3 Std.

Lektion 3: Funktionen helfen dir, deinen Code wiederverwendbar zu machen. Mit dem Schlüsselwort `def` erstellt man sie.

def berechne_flaeche(laenge, breite):
    return laenge * breite

ergebnis = berechne_flaeche(5, 10)
print(ergebnis) # Output: 50
