Nullstellen richtig berechnen

Eine Nullstelle liegt vor, wenn f(x)=0 gilt. Bei Sinusfunktionen nutzt man insbesondere: sin(u)=0 → u=k\pi, wobei k eine ganze Zahl ist. [1,2,3,4,5...]

f(x) = a · sin(b(x + c)) + d = 0

Rechenweg

1. f(x) = 0 setzen
2. d subtrahieren: a · sin(b(x + c)) = -d
3. Durch a teilen: sin(b(x + c)) = -d/a
4. Sinus umkehren: b(x + c) = sin⁻¹(-d/a)
5. Nach x auflösen und Periode [ p=2 π / b ] berücksichtigen

Wichtig

Die Verschiebung d entscheidet, ob es überhaupt Nullstellen gibt:

Wenn |d| > |a|: keine Nullstellen
Wenn |d| = |a|: genau eine Nullstelle pro Periode
Wenn |d| < |a|: zwei Nullstellen pro Periode

Beispiel 1: b und d verändert

f(x) = 2 · sin(2x) - 1 a = 2, b = 2, d = -1
Nullstelle: 2 · sin(2x) - 1 = 0
+1: 2 · sin(2x) = 1
:2: sin(2x) = 0,5
Umkehrfunktion: 2x = 0,5236 oder 2x = π - 0,5236
:2: x = 0,2618 oder x = 1,3090
Periode P = 2π/2 = π. Also: x ≈ 0,26 + kπ oder x ≈ 1,31 + kπ, k ∈ ℤ

Beispiel 2: c und d verändert

f(x) = sin(x + π/2) + 0,5 a = 1, b = 1, c = π/2, d = 0,5
Nullstelle: sin(x + π/2) + 0,5 = 0
-0,5: sin(x + π/2) = -0,5
Umkehrfunktion: x + π/2 = -π/6 oder x + π/2 = π + π/6
-π/2: x = -π/6 - π/2 = -2π/3
zweite Lösung: x = 7π/6 - π/2 = 2π/3
Periode P = 2π: x = -2π/3 + k·2π oder x = 2π/3 + k·2π, k ∈ ℤ

Beispiel 3: b, c und d verändert

f(x) = 3 · sin(2(x - π/4)) - 1,5 a = 3, b = 2, c = -π/4, d = -1,5
Nullstelle: 3 · sin(2(x - π/4)) - 1,5 = 0
+1,5: 3 · sin(2(x - π/4)) = 1,5
:3: sin(2(x - π/4)) = 0,5
Umkehrfunktion: 2(x - π/4) = π/6 oder 2(x - π/4) = 5π/6
:2: x - π/4 = π/12 oder x - π/4 = 5π/12
+π/4: x = π/3 oder x = 2π/3
Periode P = π: x = π/3 + kπ oder x = 2π/3 + kπ, k ∈ ℤ

Beispiel 4: Kosinus mit Verschiebung

f(x) = 2 · cos(x - π/3) - 1 a = 2, b = 1, c = -π/3, d = -1
Nullstelle: 2 · cos(x - π/3) - 1 = 0
+1: 2 · cos(x - π/3) = 1
:2: cos(x - π/3) = 0,5
Kosinus gleich 0,5: Winkel = ±π/3
1. Fall: x - π/3 = π/3 → x = 2π/3
2. Fall: x - π/3 = -π/3 → x = 0
Periode P = 2π: x = 0 + k·2π oder x = 2π/3 + k·2π, k ∈ ℤ

Beispiel 5: keine Nullstellen

f(x) = sin(x) + 2 a = 1, d = 2
Ansatz: sin(x) + 2 = 0
-2: sin(x) = -2
Der Sinus hat nur Werte zwischen -1 und 1. Daher kann sin(x) nie -2 sein.
Ergebnis: f hat keine Nullstellen.

Möglicher Übungstest

Übungstest: Sinus- und Kosinusfunktionen 30 Punkte

1. Gib für [ f(x)=5 ⋅ sin(2x)-3 ] Amplitude, Periode, Mittellinie und Wertebereich an. 6 P
Lösung
a = 5, b = 2, d = -3
Periode: P = 2π/2 = π
Mittellinie: y = -3
Wertebereich: [-8; 2]
2. Bestimme alle Nullstellen von [ f(x)=sin(3x-π/2) ]. 6 P
Lösung
sin(3x - π/2) = 0
3x - π/2 = kπ
3x = π/2 + kπ
x = π/6 + kπ/3, k ∈ ℤ
3. Bestimme alle Nullstellen von [ f(x)=2 ⋅ cos(x+π/4)+1 ]. 8 P
Lösung
2 · cos(x + π/4) = -1
cos(x + π/4) = -0,5
x + π/4 = 2π/3 + k·2π oder x + π/4 = 4π/3 + k·2π
x = 5π/12 + k·2π oder x = 13π/12 + k·2π, k ∈ ℤ
4. Entscheide begründet, ob [ f(x)=cos(x)+4 ] Nullstellen besitzt. 4 P
Lösung
cos(x) = -4
Der Kosinus hat höchstens den Wert -1.
Es gibt keine Nullstellen.
5. Eine Schwingung wird durch [ f(x)=1,5 ⋅ sin(2(x-π/8))+0,5 ] beschrieben. Bestimme alle Nullstellen im Intervall [0; 2π]. 6 P

x ≈ -0,060 + kπ oder x ≈ 1,631 + kπ
Im Intervall [0; 2π]: x ≈ 1,631; x ≈ 3,202; x ≈ 4,773

Mögliche Klassenarbeit

Bearbeitungszeit: 60 Minuten | Hilfsmittel: Taschenrechner

Klassenarbeit: Trigonometrische Funktionen 45 Punkte

Aufgabe 1: Zeichne [ f(x)=2 ⋅ sin(x) ] und [ g(x)=cos(x)+1 ] im Intervall [0; 2π]. Markiere jeweils die Nullstellen. 8 P
Erwartung
f: Nullstellen bei x = 0, π, 2π
g: Nullstelle bei x = π
f hat Amplitude 2; g ist um 1 nach oben verschoben.
Aufgabe 2: Für [ f(x)=3 ⋅ sin(2(x+ π/4))-1 ], bestimme Amplitude, Periode, Verschiebung in x- und y-Richtung sowie den Wertebereich. 8 P
Lösung
a = 3, b = 2, c = π/4, d = -1
Periode: P = π
Verschiebung: π/4 nach links, 1 nach unten
Wertebereich: [-4; 2]
Aufgabe 3: Berechne alle Nullstellen von [ f(x)=2 ⋅ sin(3x)+ √3 ]. 9 P
Lösung
2 · sin(3x) = -√3
sin(3x) = -√3/2
3x = -π/3 + k·2π oder 3x = 4π/3 + k·2π
x = -π/9 + k·2π/3 oder x = 4π/9 + k·2π/3, k ∈ ℤ
Aufgabe 4: Eine Feder schwingt gemäß [ f(x)=4 ⋅ sin(0,5(x + π/2))+2 ]. Bestimme alle Nullstellen im Intervall [0; 4π]. 10 P
Lösung
4 · sin(0,5(x - π/2)) = -2
sin(0,5(x - π/2)) = -0,5
0,5(x - π/2) = -π/6 + k·2π oder 0,5(x - π/2) = 7π/6 + k·2π
x = π/3 + k·4π oder x = 17π/6 + k·4π
Im Intervall [0; 4π]: x = π/3 und x = 17π/6
Aufgabe 5: Erkläre in eigenen Worten, warum [ f(x)=sin(x)+1,5 ] keine Nullstellen besitzt. 4 P
Lösung
sin(x) = -1,5
Der Sinus erreicht nur Werte zwischen -1 und 1.
Daher gibt es keine reellen Nullstellen.
Aufgabe 6: Bestimme eine mögliche Funktionsgleichung mit Amplitude 2, Periode π, Verschiebung π/2 nach rechts und Mittellinie y = -1. 6 P
Lösung
a = 2, b = 2, c = -π/2, d = -1
f(x) = 2 · sin(2(x - π/2)) - 1
