THEORIE 1

📐 Gradmaß und Bogenmaß

Ein Vollwinkel entspricht 360°. Im Bogenmaß entspricht derselbe Winkel 2π.

180° = π rad
→
Grad → Bogenmaß

Multipliziere mit π/180.

α · π / 180
→
Bogenmaß → Grad

Multipliziere mit 180/π.

α · 180 / π

THEORIE 2

〰️ Die normale Sinusfunktion

f(x) = sin(x)

Die normale Sinusfunktion schwingt regelmäßig zwischen −1 und +1.

Maximum

1

Minimum

−1

Periode

2π

Die Amplitude der normalen Sinusfunktion ist 1. Die Mittellinie ist y = 0.
THEORIE 3

🎛️ Die vier Parameter

f(x) = a · sin(b(x − c)) + d
a
Amplitude

Die Amplitude ist |a|. Bei a = −2 wird der Graph zusätzlich gespiegelt.

b
Periodenlänge

b verändert die Breite der Schwingung.

T = 2π / |b|
c
Verschiebung

x − c bedeutet Verschiebung um c nach rechts. x + c entspricht einer Verschiebung nach links.

d
Mittellinie

d verschiebt den Graphen nach oben oder unten. Die Mittellinie ist y = d.

🧩 Beispiel komplett analysieren

f(x) = 3 · sin(2(x − 1)) + 4
Parameter Wert Bedeutung
a 3 Amplitude 3
b 2 T = π
c 1 1 nach rechts
d 4 4 nach oben
Maximum: d + |a| = 7
Minimum: d − |a| = 1
Mittellinie: y = 4
Periode: π

🧠 Prüfungs-Merksatz

a = Höhe · b = Breite · c = Seite · d = oben/unten

Wenn du eine Sinusfunktion siehst, frage dich immer:

  1. Wie hoch schwingt sie? → a
  2. Wie breit ist eine Schwingung? → b
  3. Wo startet sie horizontal? → c
  4. Wo liegt ihre Mittellinie? → d
